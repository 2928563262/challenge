# 前端系统使用指南

本文档面向项目使用者，说明《伤寒论》知识图谱系统的界面操作与数据流转。

## 快速开始

### 1. 启动服务

```powershell
# 后端（Django）
conda activate challenge
cd backend
python manage.py runserver

# 前端（Vue）
cd frontend
npm install  # 首次
npm run dev
```

默认访问：`http://localhost:5173`

### 2. 主要页面

系统包含四个主要页面：

- **首页 `/`**：项目概览、统计数据和典型案例入口
- **图谱浏览 `/explore`**：实体检索、关系网络、模型抽取辅助、候选提交
- **统计图表 `/stats`**：数据可视化与图表展示
- **候选复核 `/annotations`**：查看和处理已提交的候选记录
- **模型工作台 `/models`**：模型状态与实验指标（待完善）

## 图谱浏览页（/explore）

### 功能一：关键词检索

1. 在"实体检索"区域输入关键词（如"桂枝汤"）
2. 选择实体类型（方剂、证候、症状、中药、治法、服法）
3. 点击"开始检索"
4. 结果列表显示命中实体及其统计数据（提及次数、覆盖条文数）

### 功能二：关系网络概览

1. 点击检索结果中的某个实体，右侧会显示：
   - 中心实体的基本信息
   - 入边（指向该实体的关系）
   - 出边（该实体指向的其他实体）
   - 关系证据数量
2. 点击周边节点可切换中心实体，继续探索

### 功能三：原文证据回溯

在实体详情下方显示"原文证据回溯"列表，包含：
- 条文 ID
- 行号（如有）
- 实体出现的原文片段

### 功能四：条文智能抽取

1. 在"条文智能抽取"文本框中输入一条《伤寒论》条文
2. 点击"运行 NER 抽取"
3. 系统会显示：
   - 抽取到的实体列表（类型、位置、文本）
   - 实体类型分布统计
   - 实体的图谱映射候选（如果图谱已有匹配节点）
4. 对每个抽取的实体可以进行：
   - "设为头实体" / "设为尾实体"：用于关系判断
   - "设为检索词"：用实体文本去图谱检索
   - "打开最佳映射"：直接进入图谱查看匹配节点

### 功能五：关系辅助判断

1. 从 NER 抽取结果中选择头实体和尾实体
2. 确认或修改关系判断文本（默认与抽取文本相同）
3. 点击"运行关系判断"查看模型预测结果
4. 或者使用"批量关系预测"自动判断预定义优先级的所有合法实体对：
   - 证候 → 方剂
   - 证候 → 症状
   - 方剂 → 中药
   - 方剂 → 服法

### 功能六：提交候选记录

1. 在抽取和关系判断完成后，下方"本次条文临时会话图"会显示已确定的节点和关系
2. 点击"提交候选记录"将当前结果保存到后端
3. 提交成功后可以在"候选复核"页看到该记录

### 功能七：导出临时会话图

点击"导出 JSON"可将当前会话数据下载为本地文件，包含：
- 原文文本
- 实体节点列表（包括映射候选）
- 关系边列表（包括 Top-N 预测分数）

## 统计图表页（/stats）

### 功能一：总体统计卡片

页面顶部显示核心指标：
- 清洗后条文数
- 知识节点数
- 图谱关系数
- 原文证据边数

### 功能二：实体类型分布

使用饼图展示各类型实体（方剂、证候、症状、中药、治法、服法）的数量分布。

### 功能三：高频实体排行

条形图展示提及次数最多的前 15 个实体节点。

### 功能四：关系类型分布

条形图展示各种关系类型出现的频次，用于理解图谱结构。

### 数据来源

所有图表数据从后端 `/graph/summary/` 接口获取，实时反映当前图谱状态。

## 候选复核页（/annotations）

### 筛选与搜索

- **状态筛选**：全部、待复核、已复核、已采纳、已拒绝
- **搜索**：输入记录 ID 或原文关键词进行实时筛选
- **日期范围**：选择创建时间范围
- **节点数量**：设置最小/最大节点数过滤

### 列表操作

1. 点击卡片可查看详情
2. 卡片右上角显示记录状态徽章
3. 列表支持无限滚动（当前页限制 30 条）

### 批量操作

1. 使用卡片左侧的复选框或直接点击卡片进行多选
2. 选中后顶部显示"已选 N 条"和操作按钮：
   - **清空**：取消所有选择
   - **批量采纳**：一次性将选中记录设为"已采纳"
   - **批量拒绝**：一次性将选中记录设为"已拒绝"

### 详情面板

1. **概览卡片**：
   - 记录 ID
   - 源文本
   - 节点数、关系数、创建时间
   - 状态标签

2. **已采纳的特殊操作**（针对状态为"已采纳"的记录）：
   - 导出已采纳记录（JSON）
   - 复制记录 ID

3. **状态流转**：点击下方状态按钮可更新记录状态
   - 已采纳的记录会显示绿色标识

4. **实体与关系**：以列表形式展示本次记录的节点和边
5. **原始 Payload**：完整 JSON 数据（供调试用）

## 数据流转说明

```
用户输入 → NER 抽取 → 图谱映射 → 关系判断 → 生成会话图 → 提交候选 → 人工复核 → 已采纳 → 导出回流
```

### 关键状态

- **pending**：新提交，待处理
- **reviewed**：已查看，但未定论
- **accepted**：质量合格，可用于模型重训练
- **rejected**：质量不合格，废弃

### 导出回流

`已采纳` 记录可通过复核页的"导出已采纳记录"按钮批量下载，用于后续：
- 增量训练数据构建
- 误差分析
- 图谱增量导入

## 常见问题

### Q1：NER 抽取失败？

A：检查后端模型检查点路径是否正确，确认 `models/baseline/ner/` 目录存在且包含有效模型文件。

### Q2：图谱检索无结果？

A：确认 Neo4j 服务已启动，后端图谱查询接口可访问。可能是图谱数据未导入或实体名称不匹配。

### Q3：批量操作失败？

A：可能是网络中断或后端接口异常。查看错误提示，必要时分段操作。

### Q4：如何重训模型？

A：详情见后端 `backend/scripts/` 下的训练脚本和数据处理脚本，属于"甲"的职责范围。
