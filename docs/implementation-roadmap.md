# Implementation Roadmap

## Phase 1

- 建立 `Vue + Django` 最小可运行骨架
- 接入《伤寒论》清洗文本的读取、概览和关键词检索
- 固定后端运行环境 `challenge`

## Phase 2

- 设计实体类型与关系类型的结构化存储
- 引入标注样本、规则抽取和实体关系预览接口
- 为 Neo4j 导入准备节点边导出格式

## Phase 3

- 接入知识图谱导入与查询
- 增加诊疗链条展示、条文回溯与答辩页面
- 补充模型实验记录、误差分析与演示材料

## Phase 1.5

- 在自动预标注结果上筛选 20~30 条高信息密度样本
- 构建最小人工校验集，用于 schema 修订与误差分析
